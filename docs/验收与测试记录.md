## 4. 强杀恢复验证

1. 在规则页停用「高温通风」，启用规则数从 4 变为 3。
2. 在环境页将温度拖到 39.8 ℃，页面显示命中 2 条规则、1 条冲突。
3. 等待环境防抖完成，执行 `hdc shell aa force-stop com.example.myhdzy`。
4. 重新执行 `hdc shell aa start -a EntryAbility -b com.example.myhdzy`。
5. 冷启动后环境仍为 39.8 ℃；规则页仍显示“启用 3 条”，「高温通风」仍为停用。

这次验证还发现并修复了一个持久化缺口：设备与环境仓储原先只调用
`Preferences.put`，没有立即 `flush`。修复后 `saveDevices`、`saveEnv` 与
`Boot.flush` 都有明确的落盘边界。

## 5. 已知边界

- 模拟环境代替真实传感器和执行器，不包含真实硬件抖动、网络和多用户场景。
